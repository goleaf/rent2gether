# Guest profile and compatibility

The guest profile describes practical stay needs: quiet, desk, fast internet, luggage, pets, smoking, registration, room-sharing comfort, sleep rhythm, and cleaning expectations.

The compatibility profile is used by search, booking requests, warnings, and host summaries. It should explain logistics and rule fit, such as smoking conflicts, pet conflicts, quiet needs, remote-work needs, and late-entry needs.

Compatibility warnings must not be used as discriminatory labels. They are rule and logistics explanations only. Host-facing summaries must use translated reason keys and avoid exposing private documents, exact birth dates, private locations, or internal verification metadata.
