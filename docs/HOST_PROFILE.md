# Host profile

The host profile shows safe public host information:

- host display name
- avatar
- about text
- languages
- response time and response rate
- verified host badge
- successful check-ins count
- hosting since date

Emergency contacts and representative contact details are not public by default. They may be shown only after a confirmed booking when platform rules and privacy settings allow it.

`host_representatives` are contacts or future-linked users. They are not `manager`, `staff`, or `cleaner` roles.
