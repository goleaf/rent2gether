# User privacy rules

Guests may see safe public host profile details before booking. Private host contacts, emergency contacts, documents, private notes, internal complaints, and financial details stay hidden.

Hosts may see a privacy-safe guest summary in booking/request contexts:

- public name
- avatar if allowed
- age range if allowed
- public city if allowed
- languages if allowed
- rating and completed stays if allowed
- email, phone, and identity verification status
- trip purpose and intake summary
- compatibility warnings

Hosts must not see guest documents, exact birth date, full phone number before booking, private saved locations, internal verification metadata, private notes, or raw complaint details.

Contacts open only after confirmed booking when settings and platform rules allow it.
