# Reviews

Reviews are created only from a real completed stay. Normal place reviews require a completed booking, completed checkout, real check-in, no no-show status, and an open review window.

The review flow creates requests for the guest and host after checkout. The guest can review the place, sleeping place, host, and roommate experience. The host can review the guest. One guest place review and one host guest review are allowed per booking.

Reviews use double-blind publishing by default. A submitted review stays hidden until both sides submit or until the review window expires. Public output never includes private comments, internal notes, dispute payloads, deposit details, or personal data about roommates.

Host responses are stored separately in `review_responses` and can be shown beside published public reviews.
