# Cancellation Privacy

Guests can view only cancellations for their own bookings. Hosts can view only cancellations for their hosted bookings.

Guest-facing filtered data hides internal host payout adjustment fields. Host-facing filtered data includes payout impact but does not expose private payment-provider payloads.

Future service fields and dispute context are data-only. This project still has no support, moderator, admin, or finance panel for cancellation handling.
