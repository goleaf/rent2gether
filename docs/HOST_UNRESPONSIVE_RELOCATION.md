# Host Unresponsive Relocation

If another sleeping place is available, an unresolved host-unresponsive case can create a relocation request.

Relocation uses the existing booking relocation services with source type `host_unresponsive`. The guest should not pay extra for a more expensive alternative without explicit consent.

A relocation request preserves the original booking audit trail, keeps the original sleeping place blocked until the move is applied, and lets the normal relocation consent and hold logic handle the target place.
