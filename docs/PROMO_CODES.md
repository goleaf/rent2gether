# Promo Codes

Promo codes are checked before being applied to a quote.

The engine validates:

- active state
- start and end dates
- total usage limit
- per-user usage limit
- minimum booking amount
- minimum nights
- sleeping-place, property, and host restrictions
- new-guest-only restrictions
- currency compatibility

Invalid promo codes create a non-blocking quote validation warning and do not discount the quote.
