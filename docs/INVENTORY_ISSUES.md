# Inventory Issues

`InventoryIssue` records a problem with an inventory item.

Issue types include:

- lost;
- missing;
- damaged;
- broken;
- dirty;
- not returned;
- needs repair;
- needs replacement;
- forgotten guest item.

An inventory issue can be linked to booking, check-in, checkout, cleaning, inspection, maintenance, deposit, complaint, room, property, and sleeping-place context.

Important rule:

An inventory issue does not move money automatically. It only records the reason, evidence, suggested amount, and responsibility state.

Guest responsibility can affect ratings only after confirmation, acceptance, or a resolved decision against the guest.
