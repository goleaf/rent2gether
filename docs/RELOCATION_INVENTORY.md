# Relocation Inventory

Relocation may require moving or returning inventory tied to the old place and issuing inventory for the new place.

## Common Transfers

- return old key;
- issue new key;
- return old locker;
- assign new locker;
- move or replace bedding;
- move or replace towel;
- record other issued items.

## Records

Use `booking_relocation_inventory_transfers` with:

- transfer type;
- status;
- old and new sleeping place;
- old and new room;
- optional inventory item;
- note.

Inventory transfer completion does not automatically prove the old place is safe to reopen. Cleaning, inspection, repair, forgotten items, complaints, and damage checks still control reopening.
