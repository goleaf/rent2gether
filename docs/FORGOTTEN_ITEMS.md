# Forgotten Items

Forgotten items are tracked in `booking_forgotten_items` and linked to:

- booking check-out;
- booking;
- guest;
- host;
- property;
- room;
- sleeping place.

The host can record item name, description, photo path, storage location, return method, and status.

Statuses:

- `found`;
- `guest_notified`;
- `waiting_guest_response`;
- `return_arranged`;
- `returned`;
- `disposed`;
- `closed`.

Forgotten item details are private to the booking participants and are not shown in public listings or roommate summaries.
