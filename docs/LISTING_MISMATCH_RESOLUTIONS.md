# Listing Mismatch Resolutions

Resolution options are stored separately from the report so guest and host can review each offer.

Supported resolution types include:

- explanation
- fix problem
- provide missing item
- cleaning
- repair
- partial or full refund
- compensation
- relocation
- cancellation
- dispute or complaint

Simple, safe issues should prefer a soft resolution first. Serious or unsafe reports can move directly to relocation, cancellation, refund, complaint, or dispute.
