# Host Unresponsive Cancellation and Refund

Confirmed host unresponsive cases should be guest-friendly.

When the guest cannot check in because the host did not respond, cancellation uses `host_unresponsive_related` and reason `host_unresponsive`. Refund previews and cancellation records still go through the normal booking cancellation services so accommodation, cleaning fee, service fee, deposit, penalties, and refund records stay separated.

The deposit should normally be returned if the guest never received access and did not damage the place. Cleaning fee should normally be refunded when the guest did not stay. Service fee follows platform policy.

Calendar locks may be released after cancellation before check-in, unless the access problem means the place should remain blocked until fixed.
