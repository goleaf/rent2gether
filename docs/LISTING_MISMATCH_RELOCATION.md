# Listing Mismatch Relocation

Relocation can be offered when the booked sleeping place is materially different from the booking snapshot or unsafe to stay in.

The relocation record stores:

- original booking
- current sleeping place
- new sleeping place when available
- source type `listing_mismatch_report`
- source id of the mismatch report

If the new place is more expensive, the guest should not pay extra unless they explicitly accept that difference. Confirmed mismatch defaults toward host/no-extra-charge handling.
