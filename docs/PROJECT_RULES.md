# Project Rules

## Product

This repository is a mobile-first Laravel 13 marketplace for renting individual sleeping places inside properties and rooms.

## Hard constraints

- Laravel 13
- Livewire 4
- Flux Pro
- SQLite
- Blade server-side rendering
- No Volt
- No Filament
- No Inertia
- No React or Vue
- English and Russian from day one

## Product hierarchy

User -> Host profile -> Property -> Room -> Sleeping place -> Availability -> Booking -> Stay -> Review / Payout / Complaint

## UI rules

- Mobile first at 320px wide
- Small DOM
- Lazy load below-the-fold content
- No heavy map on first screen
- No huge selects
- Use translated strings everywhere
- Use friendly copy
