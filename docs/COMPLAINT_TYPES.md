# Complaint Types

Complaint types describe the problem without deciding blame. Supported examples include check-in problems, dirty rooms, listing mismatch, missing amenities, noisy or aggressive neighbors, host unresponsive cases, guest rule violations, theft, property damage, safety, discrimination, fraud, payment, refund, deposit, cancellation, relocation, extension, inventory, forgotten items, and other.

Severity controls urgency:

- `low`: small issue, usually solved by message.
- `medium`: affects the stay and needs action.
- `high`: serious stay impact and may need refund, repair, or relocation.
- `urgent`: quick action required.
- `emergency`: possible danger; show emergency guidance.

Unconfirmed complaint types must not directly affect rating or search. Rating/search integrations run only from explicit services after confirmation or serious safety rules.
