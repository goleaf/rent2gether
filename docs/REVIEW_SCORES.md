# Review Scores

Detailed scores live in `review_scores`. Each score stores a metric key, value, max score, weight, and public flag.

Guest place scores include cleanliness, safety, sleeping place quality, mattress quality, noise, internet, value, amenities, and problem resolution. Host guest scores include rules respect, cleanliness after stay, communication, punctuality, respect for roommates, care for property, and payment reliability.

MVP scores use the 1-5 scale. Weighted fields are present for future ranking without changing the schema.
