# Price Snapshots

Booking price snapshots freeze the final accepted quote price.

`booking_price_snapshots` stores:

- pricing settings snapshot
- quote line snapshot
- discount snapshot
- promo code snapshot
- accommodation before and after discount
- fees
- deposit
- guest and host service fees
- total payable
- host payout
- refundable and non-refundable amounts

Future host pricing changes must not update existing booking snapshots.
