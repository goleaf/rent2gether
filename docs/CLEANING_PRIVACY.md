# Cleaning Privacy

Guests must not see operational details that do not affect them.

Hidden from guests:

- internal host notes;
- responsible person contact details;
- internal media;
- future-review-only media;
- private issue details unless they affect the guest-facing booking state.

Hosts can view and manage tasks for their own properties. Responsible users can view/manage assigned tasks without creating a cleaner role.

Guest filtering returns safe status summaries only.
