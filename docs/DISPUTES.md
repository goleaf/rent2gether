# Disputes

A dispute is separate from a complaint. Complaints describe problems; disputes describe disagreement about the outcome, money, deposit, cancellation, refund, no-show, host-unresponsive, mismatch, payment, relocation, damage, safety, or other conflict.

Disputes can open from a complaint, deposit case, cancellation, refund, no-show, or host-unresponsive case. They store booking, property, room, sleeping-place, guest, host, source ids, disputed amount, freezes, proposals, and decisions.

The main flow is:

1. A participant opens a dispute from a contested source.
2. Related effects can be frozen.
3. Both sides can add evidence and messages.
4. Either side can propose a resolution.
5. If both accept, a mutual-agreement decision is recorded.
6. A decision is applied and freezes are released.

Future reviewer fields are data-only. They do not create support, moderator, staff, or admin panels.
